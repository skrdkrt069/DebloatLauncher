# DebloatLauncher

Launcher interno para execução do **Debloat Installer**.

## Sobre

O DebloatLauncher serve como ponto de entrada para o instalador de ferramentas de manutenção e otimização do Windows.

## Execução

Baixe ou clone o repositório e execute:

`DebloatLauncher.exe`

## Observações

* Projeto de uso interno.
* O instalador principal é armazenado utilizando **Git LFS** devido ao seu tamanho.
* Requer Windows.
